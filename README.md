## Опис роботи

У межах лабораторної роботи реалізовано сортування списку об'єктів класу `Student` стандартними засобами мови Python (`sorted()`) за кількома критеріями та досліджено стабільність сортування:
1. **За прізвищем** — за абеткою (`key=lambda s: s.surname`).
2. **За середнім балом** — від вищого до нижчого (`key=lambda s: s.grade, reverse=True`).
3. **Складене сортування** — за групою (первинний ключ), а всередині кожної групи — за середнім балом від вищого до нижчого (`key=lambda s: (s.group, -s.grade)`).
4. **Перевірка стабільності (Timsort)** — аналіз поведінки однакових значень та додаткове сортування за балом від вищого до нижчого з впорядкуванням однакових балів за прізвищем (`key=lambda s: (-s.grade, s.surname)`)[cite: 6].

## Як запустити проєкт

1. Переконайтеся, що на комп'ютері встановлено **Python 3**:
   ```bash
   python --version
   ```

2. Перейдіть у папку лабораторної роботи `lab05`:
   ```bash
   cd lab05
   ```

3. Запустіть скрипт у терміналі:
   ```bash
   python lab05.py
   ```
   *(На Linux або macOS може знадобитися команда `python3 lab05.py`)*

## Результат виконання

Після запуску `lab05.py` у консоль послідовно виводяться відсортовані списки студентів для кожного із завдань:
1. Список, відсортований за прізвищем за абеткою.
2. Список, відсортований за середнім балом від вищого до нижчого.
3. Список, відсортований за назвою групи, а всередині групи — за балом від вищого до нижчого.
4. Список, відсортований за балом від вищого до нижчого, де студенти з однаковим балом впорядковані за прізвищем за абеткою[cite: 6].
